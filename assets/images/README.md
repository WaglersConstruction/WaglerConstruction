# Project photos

Place optimized project photos in this folder using these filenames:

- `project-01.jpg` — residential metal roof installation
- `project-02.jpg` — metal roof replacement
- `project-03.jpg` — roof trim or flashing detail
- `project-04.jpg` — garage or outbuilding metal roof
- `project-05.jpg` — new deck construction
- `project-06.jpg` — deck rebuild or replacement
- `project-07.jpg` — porch, steps, or landing
- `project-08.jpg` — deck rail or finish carpentry

The homepage retains a styled placeholder for any filename that is absent.
Landscape photos work best. Crop or resize each photo to approximately 1200–1600
pixels wide and compress it for the web before committing.
