# Project photos

Upload project photos to this folder and the website will add them to the
Recent Projects gallery automatically. Exact filenames are no longer required.

Supported formats are JPG, JPEG, JFIF, PNG, WebP, GIF, AVIF, and BMP. HEIC and
TIFF photos should be converted to JPG before uploading because many browsers
cannot display those formats.

Use a short, descriptive filename such as `howell-red-metal-roof.jpg` or
`new-deck-and-steps.png`. The website turns the filename into the photo caption,
so descriptive names are more helpful than names such as `IMG_1234.jpg`.

Landscape photos work best. Resize photos to approximately 1200–1600 pixels
wide and compress them for the web when practical. Avoid uploading the same
photo more than once under different extensions; exact duplicates are hidden
automatically.
